 🎬 Netflix Clone

A responsive Netflix Clone website built using HTML and CSS only.
This project recreates the look and feel of the Netflix homepage while focusing on frontend design, layout, responsiveness, and CSS styling.

 🛠️ Technologies Used

* HTML5 – Used to structure the website
* CSS3 – Used for styling, layout, animations, and responsiveness

 ✨ Features

* 🎬 Netflix-inspired homepage design
* 📱 Responsive layout for different screen sizes
* 🎨 Modern and clean UI
* 🖼️ Movie/show posters and background images
* 🔥 Hero section with Netflix-style content
* 📺 Movie and TV show sections
* 🎯 Navigation bar and footer
* 💻 Built completely with **HTML & CSS**
* ⚡ No JavaScript or frameworks used

 📚 What I Learned

While building this project, I practiced:

* HTML semantic structure
* CSS Flexbox
* CSS Grid
* Positioning and layouts
* Responsive web design
* Background images
* CSS selectors
* Spacing, margins, and padding
* Creating Netflix-style UI components
* Organizing frontend project files
